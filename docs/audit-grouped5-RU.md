# Проверка Menu Bar Dock Grouped

Дата: 15 октября 2026. Результат: grouped.5, на основе Menu Bar Dock 4.8.0 (`027f622`). Проверены исходники приложения, модели состояния, меню, настройки, запуск, обработка уведомлений, скрипты сборки и упаковка. Просмотр экрана пользователя не выполнялся.

## Найденные ошибки и исправления

| Проблема | Что исправлено |
|---|---|
| В таблицу можно было перетащить обычный текст и передать неверный индекс | Собственный тип pasteboard, проверка источника drag и границ; перестановка выбранных строк одним действием |
| Ползунки игнорировали клавиатуру и accessibility | Все действия применяют значение; тяжёлое обновление списка во время mouse-drag ждёт отпускания кнопки |
| Активация accessory-приложения оставляла скрытым предыдущее обычное приложение | Все уведомления активации обновляют состояние активного процесса |
| Блоки уведомлений удерживали AppTracker после удаления | Слабые ссылки и удаление всех токенов наблюдения в deinit |
| Нулевой лимит показывал одно приложение; отрицательный мог вызвать ошибку suffix/prefix | Ноль соблюдается, диапазон лимита проверяется, доступ к настройкам обеспечивает отдельная кнопка пустой группы |
| Некорректные числовые настройки могли попадать в геометрию | Проверены конечность и диапазоны; URL закреплений фильтруются и освобождаются от дублей |
| Одинаковый URL нескольких процессов смешивал их историю активации | Сортировка по отдельному процессу; завершение одного экземпляра не удаляет историю соседнего |
| Алфавитный режим зависел от истории активации | Сортировка по отображаемым именам |
| Номер экземпляра обрезался на крупных иконках | Значок привязан к нижней видимой границе слота |
| Ползунок отступа мог оставаться со старым значением после изменения через меню | Синхронизация существующих настроек, повторное использование окна |
| В обработчике запуска игнорировалась ошибка; завершившийся handle мог попасть в activate | Ошибка показывается после пользовательского действия; остановленный процесс запускается заново |
| Локальный автозапуск не работает на macOS 11/12, хотя checkbox был активен | Контроль выключен на этих версиях, с пояснением о macOS 13+ |

## Снижение нагрузки

Кнопки повторно используются вместо удаления и создания при каждом событии. Кэш кнопок хранит только текущие видимые элементы и отдельный overflow-контроль. Контроллеры скрытых пунктов создаются при открытии меню и сохраняются на время его работы.

Объекты закреплений и обычные иконки повторно используются. Кэш обновляется при изменении списка, открытии настроек и изменениях смонтированных томов. Пользовательские иконки декодируются один раз через NSCache с лимитами количества и стоимости; NSCache освобождает объекты при давлении на память. Повреждённые изображения дают обычную иконку.

Серия событий приложения объединяется в один проход главной очереди. Все модели получают один снимок процессов. Изменение отступа, размера иконок и ширины кнопок не читает процессы и не пересобирает модели приложений. Неизменившиеся настройки не записываются повторно; изменение отступа пишет только его ключ. В локальной версии отладочный журнал по умолчанию выключен; выключенный журнал не форматирует сообщения. Таймеров постоянного опроса не добавлено.

## Измерения

Сравнение grouped.4 с grouped.5 на этом Mac. Релизная компиляция с `-O`, одинаковые сценарии, прогретый кэш, медиана трёх повторений. В каждой ячейке — суммарное время указанного числа операций. Иконка — PNG 256×256, как при обычном сохранении через настройки.

| Операция | Повторов | grouped.4 | grouped.5 | Ускорение операции |
|---|---:|---:|---:|---:|
| Обновление 12 закреплённых папок | 300 | 230.955 мс | 7.841 мс | 29.5× |
| Обновление панели из 12 элементов | 1000 | 1153.829 мс | 39.703 мс | 29.1× |
| Повторное получение пользовательской PNG-иконки | 1000 | 57.398 мс | 0.168 мс | 341.7× |

Это микротесты отдельных операций. Они не измеряют общий CPU%, потребление энергии или срок работы от батареи. Холодный старт и создание новой иконки по-прежнему требуют загрузки ресурсов. Ускорение операции нельзя переносить на всё приложение.

Воспроизведение: `scripts/benchmark-grouped.sh`. Полные результаты сохранены в `performance-before.csv` и `performance-after.csv`.

## Проверки

- 79 нативных проверок прошли. Покрыты прежние функции, миграция, иконки и индикаторы, 45 комбинаций геометрии, кэши и их освобождение, клавиатурное управление, перестановка строк, отрицательные/нулевые лимиты, состояние активного приложения, восстановление доступности папок и реальные обработчики AppDelegate.
- Проверка AppDelegate подтверждает ноль запросов процессов при изменении внешнего вида и один общий запрос при серии событий. Сохранение неизменившихся настроек вызывает ноль записей; изменение отступа — одну.
- Релизная arm64-сборка завершилась успешно, ad-hoc подпись проверена. Зависимости executable — системные библиотеки и frameworks; Sparkle в локальный executable не включён.
- Проверены синтаксис shell-скриптов, plist/Xcode project и `git diff --check`.
- Тесты интерфейса рисовали собственные невидимые элементы и не читали экран пользователя.

## Ограничения проверки

Xcode не установлен, поэтому полные Xcode/XCTest и UI automation targets не запускались. Ручная проверка клика по папке, ⌘-перетаскивания, расположения на нескольких экранах и полного сценария двух одновременно запущенных копий остаётся за пользователем. Регистрация автозапуска и реальное открытие внешних приложений намеренно не менялись в ходе тестов. На старых версиях macOS runtime-проверки не выполнялись.

В релизной сборке остаётся предупреждение об устаревшем API в унаследованном обходном пути запуска Steam. Оно не является ошибкой компиляции; поведение Steam на этом Mac не проверялось. Нативные проверки также показывают предупреждения устаревших API исходного интерфейса; они не препятствуют выполнению тестов.

Проверка не доказывает отсутствие всех возможных ошибок. Подтверждённые проблемы выше исправлены, а ограничения перечислены явно.
